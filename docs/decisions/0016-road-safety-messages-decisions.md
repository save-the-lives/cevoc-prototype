## Decisions
1. Only ONE message is shown, the most relevant by priority. The cap of one replaces the earlier proposal of two or three (answers question 1 of 0012).
2. Each program block has an on/off switch for messages (`messages`), inherited from the default block when silent (record 0014). The rule date range (`active_from`, `active_to`) applies.
3. NO messages in the PDF evidence pack (answers question 6 of 0012).
4. Tone: plain, informative, never accusatory (answers question 3).
5. Wording approval is the owner's. The approval is recorded beside each message in the configuration (`approved_by`, `approved_on`) (answers question 2).
6. Staff visibility of which rule fired is DEFERRED (question 5 of 0012). The shown "why am I seeing this" line naming the rule id is therefore not part of the first build.
