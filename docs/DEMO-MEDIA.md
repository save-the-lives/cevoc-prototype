# Demo media manifest

The data file is `docs/demo-media-manifest.json` (the build script reads it). This page is the readable view. Rule: **no file without a recorded source, author, licence and licence URL**, and no file without a recorded privacy check. The bundle build refuses anything else (`scripts/build-demo-bundle.mjs`), and so does the app's loader.

## Status of the realistic-media task (read this first)

The owner asked for realistic, copyright-free photographs and short clips of roads, cars and traffic cameras (Wikimedia Commons, Pexels, Pixabay, government open data). **None could be added in this step.** The build sandbox's network allows only package registries and GitHub, so every media source was unreachable: `commons.wikimedia.org`, `upload.wikimedia.org`, `en.wikipedia.org`, `www.pexels.com`, `pixabay.com`, `images.unsplash.com`, `archive.org`, `www.loc.gov` (proxy refused, checked 2026-11-05). Per-file licences could not be read, so nothing was guessed. Nothing is in the bundle that has no recorded licence.

The existing `frontend/public/samples/image-1.jpg` and `image-2.jpg` (and the `prototype/public/assets/media` set they were copied from) are photographs whose source and licence are **not recorded anywhere in the repository**, and their banner text is baked into the picture. They are therefore NOT in the manifest or the bundle, and the owner should confirm where they came from or replace them (see Owner actions).

## Which case uses which media

Every case that returns images uses the images of the active media source; the case picks them by its sequence number from the image set, so a case always shows the same pictures. A case with a video uses the first video. When no bundle is configured the built-in generated SVG sample images and the sample video are used. Licences: all of the above are project-original (see the table); the built-in SVG samples are generated by `SampleMediaSource` and are project-original as well. No third-party licence applies to any case today, so no attribution is required in the app's demo credits.

| Cases | Images | Video | Licence |
|---|---|---|---|
| Every case with images (see the scenario table in `DEMO-DATA.md`), bundle configured | `sample-image-1.svg` and `sample-image-2.svg`, chosen by sequence | `sample-video-1.mp4` where the case has video | Project-original |

## Adding real openly licensed media later

1. Check the licence of each file individually on its source page (public domain or CC0 preferred; attribution licences are allowed if the credit is shown in the demo credits).
2. Look at the image itself: no identifiable person, no legible plate except the intended vehicle's clearly fictitious plate. Otherwise blur by a documented step before adding, and say in `privacy.method` what was done and how it was checked.
3. Add one entry to `docs/demo-media-manifest.json` with `sourceUrl`, `author`, `licence`, `licenceUrl`, `credit`, `retrieved`, `shows`, `privacy`, optional `banner` lines, and update the table above. Bump `bundleVersion`.
4. Never use real enforcement evidence, real notices, or anything from a government system.
